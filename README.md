# Markdown Reader

Chrome 扩展：当 Chrome 打开本地 `.md` / `.markdown` 文件时，自动渲染为 HTML 阅读页。

插件图标文件位于 `icons/` 目录，`manifest.json` 已配置扩展图标和工具栏图标。

## 安装

1. 打开 Chrome，进入 `chrome://extensions/`。
2. 开启右上角「开发者模式」。
3. 点击「加载已解压的扩展程序」。
4. 选择本仓库目录。
5. 在扩展详情中开启「允许访问文件网址」。

## 使用

在 Finder 中选中 Markdown 文档，选择用 Chrome 打开。文件 URL 以 `.md`、`.markdown`、`.mdown` 或 `.mkd` 结尾时，扩展会自动把内容渲染成 HTML 阅读页。

如果本地文件没有自动渲染，点击浏览器右上角的 Markdown Reader 图标，按弹窗提示开启「允许访问文件网址」。这是 Chrome 对 `file://` 文件的安全限制，扩展无法自动开启。

支持标题、段落、加粗、斜体、删除线、链接、图片、代码块、引用、列表、任务列表、表格和分割线。

当文档包含多个标题时，阅读页左侧会显示目录导航，可快速跳转到对应章节。目录默认展示 1 到 3 级标题。

阅读页右上角有主题切换按钮，可在浅色和黑色模式之间切换。选择会保存在浏览器本地，下次打开 Markdown 文档时继续沿用。
