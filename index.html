在 Chrome 里直接阅读本地 Markdown 文件

Markdown Reader 会把本地 .md、.markdown、.mdown 和 .mkd 文件渲染成清爽的阅读页面，支持左侧目录导航、表格、代码块和浅色/黑色主题。

本地处理文件内容只在浏览器中处理，不上传服务器。
无需账号安装后即可使用，不需要登录或云端同步。

开启本地文件访问后即可使用

Chrome 默认不会自动授予扩展 file:// 文件访问权限。安装后按三步开启一次，本地 Markdown 文件就能自动渲染。

1

安装扩展

从 Chrome Web Store 安装 Markdown Reader。

2

允许访问文件网址

进入扩展详情页，开启“允许访问文件网址”。扩展弹窗也会提供三步提示。

3

打开 Markdown 文件

在 Finder 中选择 .md 文件，用 Chrome 打开后会自动渲染阅读页。

面向本地阅读，不做云端同步

Markdown Reader 只解决一件事：让本地 Markdown 文件在 Chrome 中更容易阅读。它不要求登录，不上传文档，也不依赖云端服务。
